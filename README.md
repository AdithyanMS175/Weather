<h1>🌦️ Weather Website</h1>

A simple weather website built using HTML, CSS, Bootstrap, and JavaScript.
This project is created for learning and practicing API calls — specifically using the OpenWeatherMap API to fetch real-time weather data.

<h3>🧠 Project Purpose</h3>

This project was made to:

Understand how to call APIs using JavaScript fetch().

Learn how to display dynamic data on a webpage.

Practice basic frontend design using Bootstrap and CSS.

Explore handling JSON responses from external APIs.

<h3>🛠️ Tech Stack</h3>

HTML5 – Structure of the web page

CSS3 / Bootstrap 5 – Styling and responsive layout

JavaScript (ES6) – Fetching data and DOM manipulation

OpenWeatherMap API – Source of weather data

<h3>⚙️ How It Works</h3>

User enters a city name in the search box.

The website sends a request to the OpenWeatherMap API using JavaScript fetch().

The API returns current weather details in JSON format.

The data is displayed on the page — temperature, humidity, wind speed, pressure, and weather condition.

<h3>🚀 How to Run</h3>

Clone or download this project:

git clone https://github.com/AdithyanMS175/Weather.git


Open the project folder.

Open the file index.html in your browser.

Type a city name and click Search — the weather info will appear.

🔑 API Setup

Get your free API key from OpenWeatherMap



Save the file and reload the page.
